# URBAN TEXTURES / 城市感官转译实验室

同济大学《设计、生活与创新》课堂工具。从实拍图中采集色彩与视觉重心，构成抽象图形，再由声音驱动。

## 使用

用 Chrome 或 Edge 打开 [dist/index.html](dist/index.html)。也可双击 **启动城市感官转译实验室.cmd**。离线成品包含脚本、样式与内置样本。学生的图像和录音在本机浏览器处理。

1. 在右侧上传图像与音频。画布下方提供播放、暂停、重播和定位。
2. 点击图形键选择参与构图的形状。亮起的按键参与生成。点击 **随机分配** 会改变递归切分、主形分配和细节。用 **最小基础体素** 控制切分下限，用 **体素大小差异** 控制形体尺寸的跨度。
3. 动态键可以独立开启或叠加。重影也可单独随声音展开。所有按键均可用 Tab 聚焦并用空格操作。
4. **细调** 内可选择样本，调整细节密度、色彩归纳、画布底色、动力或重影。也可以输入种子复现某次构图。
5. **保存画面** 下载当前画布 PNG。**录制视频** 从当前播放位置采集画布与声音。停止后下载 MP4 或 WebM。全屏可按 Esc 退出。
6. **保存配置** 下载 JSON。它包含生成种子、参数和素材名称。跨设备恢复个人作品时请携带原始素材。

## 提取和颜色

带种子的递归切分决定形体的位置和尺度。每个分区使用源图的局部颜色，边缘与对比度影响切分优先级。十字、长线与线框环可以占据大分区。相近色区用作动态分组。局部采样色经过提亮和增饱和，接近色域边界时同步收缩色差以保持色相关系。

## 声音与三维

低频和慢包络驱动群组迁移。中频与瞬态推动聚散和分批翻转。线条沿自身方向伸缩与摆动，圆与环的呼吸更明显，十字更强调角度变化，方与矩形保留块面位移和翻面。暂停后画面回到静态构图。

薄片顶点绕 X、Y 轴旋转，经透视相机投影到同一张 Canvas。正反面的色彩、光照和片边厚度可区分，群组根据深度绘制。残像使用独立轮廓，轨迹模式会从过去约半秒的位姿取样，包含群组移动与空间翻转。

## 开发和验证

本目录使用 Node.js 22 或以上版本。独立复制源码后首次构建需运行 `npm install`。

```sh
npm run build
npm test
npm run test:browser
```

| 模块 | 职责 |
| --- | --- |
| `image.js`、`geometry.js` | 图像分析、连通色区、形状筛选、局部取色 |
| `audio.js` | Web Audio 播放链、FFT、包络与瞬态检测 |
| `choreography.js`、`motion.js` | 群组轨迹、组内形变、残像历史 |
| `projection.js`、`renderer.js` | 三维透视、面片光照和 Canvas 输出 |
| `app.js`、`settings.js`、`export.js` | 操控、配置、PNG 和同步音画录制 |

浏览器测试默认使用本机 Edge。设置 `URBAN_REFERENCE` 为夕阳参考图的本机路径可执行原图场景检查。设置 `URBAN_SCREENSHOT` 为一个 PNG 文件路径可保存验收截图。

图片上限 36 MB、4800 万像素，作品画布长边最多 1536 px。音频上限 120 MB。视频单次最长 90 秒，采集上限 30 FPS，录制时保持页面前台。旧版 JSON 可以导入，旧构图会按新版规则重新生成。
